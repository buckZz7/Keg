Compression race

Produce the smallest model that still is the model.

Keg is a race to quantize a model down as far as it will go before it stops being recognizably itself. Every submission is measured against a public, re-derivable reference — the model's own next-token behavior. The smallest recipe that passes takes the crown.

How it works

A submission is a real, loadable model file. The house serves it and measures two things against the reference: top-1 agreement (primary) and KL divergence within a bound (secondary). No seed baselines, no judge — either it still is the model, or it isn't.

The board

Receipts are the source of truth. Only accepted recipes appear; the crown is the smallest accepted. Each run posts a hash-bound, replayable receipt.

Submit a recipe

Add a JSON recipe as recipes/<handle>.json in a pull request. The model file must be a real GGUF of the lane's architecture — a lookup table or answer store is rejected before any measurement.

What we do

Validate the file → serve it → measure top-1 + KL vs the reference → post a hash-bound receipt → update the board. Full rules in RULES.md.

The reference

The yardstick is the model's own next-token behavior, generated once from the BF16 weights over a public corpus — open and re-derivable by anyone. No sealed corpus, no hidden authority.

Corpus

Prose, knowledge, multilingual, technical, and code — public-domain and permissive-licensed. Pinned by hash so every receipt binds to the exact yardstick.
